DELIVERY ARTIFACTS / AZURE TEST PLANS

From cases to execution.

Select cases, provide your project fields and download an Azure Test Plans CSV. Each step keeps its own action and expected result.

01 · Choose the source

Default: local framework contract cases. Upload your reviewed product cases using the same JSON schema. No test results or pass statuses are invented by exporting.

02 · Set Azure project fields

Use an existing Area Path, a valid organization user and a state allowed by your process. IDs stay empty for new cases. Import once, then use Azure's exported IDs for future updates.

03 · Select and download

Import instructions

Import into Azure Test Plans

Open Test Plans → select a plan and suite → Import test cases from CSV/XLSX → select the downloaded CSV → review mappings → Import.

CSV generation is validated locally. No Azure tenant import has been performed. CSV import creates manual test case work items; linking automated test results is a separate pipeline configuration.
