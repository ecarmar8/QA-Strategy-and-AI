# Skills · purpose, inputs and outputs

35 reusable procedures encode the method. Each receives sources and scope, applies professional reasoning and returns a reviewable artifact. Client entry points load the same authoritative procedure. Tools are used only when the actual task and available capability justify them.

| ID | Skill / when to use | Inputs | Output | Practice |

## Selecting skills

Use 00 to coordinate; 31 and 32 apply throughout. Discovery and diagnosis precede a prescription. Choose functional/non-functional, data, API/UI and automation tracks from actual risk, not the catalog order. Use [problem patterns](problem-solving.md) for an investigation path and [LLM clients](llm-clients.md) for discovery/invocation.
