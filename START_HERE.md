# Begin a QA engagement

Start by understanding the product, people and actual delivery process. The methodology is independent of sector, work-management product, LLM or browser tool. No connection setup or demonstration is a prerequisite for discovery.

1. Read [QA_STRATEGY.md](QA_STRATEGY.md) for the complete operating strategy.
2. Use [ENGAGEMENT_PLAN.md](ENGAGEMENT_PLAN.md) to organize discovery, diagnosis and the first improvement cycle.
3. Apply [00-orchestrate-testing-lifecycle.md](00-orchestrate-testing-lifecycle.md), the shared contract and only the procedures needed for the current task.
4. Capture real sources and decisions using [PROJECT_TEMPLATES.md](PROJECT_TEMPLATES.md), reusing existing equivalent artifacts.
5. Generate an English evidence-based report using [PROCESS_RISK_KPIS.md](PROCESS_RISK_KPIS.md) and [HTML_REPORT_GUIDE.md](HTML_REPORT_GUIDE.md).

## Initial instruction

```text
Apply QA_STRATEGY.md, ENGAGEMENT_PLAN.md and skill 00.
Start with product, team and current delivery discovery.
Use my available real sources; identify the missing inputs
that affect decisions and continue independent useful work.
Do not assume a business sector, Scrum, Azure DevOps,
Playwright, an execution environment or a cause of defects.
Map the actual process, review relevant escape evidence,
establish a baseline and propose one focused improvement.
Use PROJECT_TEMPLATES.md where existing artifacts are absent.
Keep project artifacts and the executive report in English.
Use PROCESS_RISK metrics; exclude financial KPIs.
Do not claim implementation, execution or approvals without evidence.
```

For an existing engagement, resume its checkpoint and recheck changed inputs instead of restarting discovery. Tool installation is optional implementation support in [SKILLS_INSTALLATION.md](SKILLS_INSTALLATION.md). Browser work, if actually needed, uses [PLAYWRIGHT_MCP_SETUP.md](PLAYWRIGHT_MCP_SETUP.md).

For the CapRelease CTO discussion, use [the role profile](profiles/caprelease/QA_ENGAGEMENT_STRATEGY.md) and [the executive brief](profiles/caprelease/CTO_BRIEF.md) after the general strategy.
